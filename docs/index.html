FENGSHUI NAQI PAN / OPEN SOURCE 1.0.0

图形能复算，
解释有条件。

在自行绘制的平面图上，核对门向、取心与红蓝分区。三套原始输入，六组真实工具输出，全部可离线复现。

公开仓库与安装版本下载矩形办公室L形住宅歧义重算

红6/7/8/9按本套传统约定为纳气区，蓝1/2/3/4为水位区。数字为旋转后的盘区编号；不代表科学验证的健康、财富或经营预测。本站无上传表单、跟踪器或模型调用。

一条命令，六组计算

python3 -m pip install -r requirements.txt
python3 scripts/make_demos.py --out runs/demo-001

需Python 3.10+及Pillow。输出目录必须是新目录。安装后计算和页面离线运行；直接下载本仓库，也可在浏览器打开docs/index.html。原始图、模拟问答和解释是预写教学示范；叠图、JSON与几何记录是工具实际生成，没有伪装的模型评测结果。
